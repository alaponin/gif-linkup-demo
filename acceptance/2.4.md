# Acceptance check — module 2.4 (PLR enrolment service published)

**Proves:** the Learner Registry provides its enrolment service on the bus, with
access granted to exactly the policy's consumers.
**Run by:** `scripts/acceptance.sh` (SS admin REST API)

- **Given** modules 2.1–2.4 are deployed and `scripts/seed.sh` has run;
- **When** the check queries the ss-plr admin API for clients, service
  descriptions and access rights of `enrolment-api`;
- **Then**
  - client `PROGRESSA/GOV/PLR/ENROLMENT` is `REGISTERED`;
  - service `enrolment-api` (OpenAPI3) is **enabled**, service URL
    `http://app-plr:8000/v1`;
  - the access-rights list of `enrolment-api` contains exactly
    `PROGRESSA/GOV/PNEA/EXAMS` — **one entry, no more** (the deny side of the ACL
    is exercised live in 2.6);
  - `app-plr` answers a direct health probe and reports the seeded enrolment count.
