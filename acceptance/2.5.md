# Acceptance check — module 2.5 (PNIA identity service published)

**Proves:** the National Identity Authority provides its identity service on the
bus, field-limited per the decree, with access granted to exactly the policy's
consumers.
**Run by:** `scripts/acceptance.sh` (SS admin REST API)

- **Given** modules 2.1–2.5 are deployed and `scripts/seed.sh` has run;
- **When** the check queries the ss-pnia admin API (lite profile: ss-plr) for
  clients, service descriptions and access rights of `identity-api`;
- **Then**
  - client `PROGRESSA/GOV/PNIA/IDENTITY` is `REGISTERED`;
  - service `identity-api` (OpenAPI3) is **enabled**, service URL
    `http://app-pnia:8000/v1`;
  - the access-rights list of `identity-api` contains exactly
    `PROGRESSA/GOV/PNEA/EXAMS` — one entry, no more;
  - a direct probe of `app-pnia` returns only the purpose-limited fields
    (`nin, given_name, family_name, date_of_birth, sex, region`) — no field
    beyond the decree's list.
