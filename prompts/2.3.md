# Generating prompt — module 2.3 (Register PNEA — the consumer)

**Building block(s):** member-pnea
**Produces:** `configs/member-pnea/2.3.yaml`
**Public spec:** NIIS X-Road member and subsystem registration; Security Server user guide (consumer connection types)

## Problem

The examination authority is the consumer side of the once-only exchange: it
provides no services in this slice but must be registered on the bus and configured
so its information system can make calls through its Security Server. This prompt
generates the consumer registration. Precondition: PNEA has passed the Member
Requirements checklist (Module 5.2; Interop Toolkit).

## Prompt (copy-paste ready)

```
Below is the NIIS X-Road member/subsystem registration reference (including
consumer connection types) and the Progressa service brief for the National
Examination Authority (PNEA) [paste both].

Generate the consumer-registration configuration as a single YAML document:
(1) member — instance, member_class, member_code, member_name;
(2) subsystem — code and description;
(3) security_server — code and DNS name;
(4) client.connection_type — how the consumer information system connects to its
    own Security Server (HTTP for the demonstration, marked demo-only; HTTPS with
    a client TLS certificate for production);
(5) consumes — the two provider services this member will call, as full X-Road
    service identifiers.

Rules: every identifier is [confirm: verify against the live X-Road registry].
The consumes list must use identifiers exactly as frozen in manifest.yaml — do not
restate them from memory. Output only the YAML document.
```

## Inputs / outputs

- **Inputs:** the registration spec + the PNEA service brief + the frozen
  identifiers from `manifest.yaml`.
- **Output:** `configs/member-pnea/2.3.yaml`, applied by `scripts/deploy.sh`.

## Safeguard

The consumer's default connection type (HTTPS) fails the demo call unless a client
TLS certificate is uploaded — set HTTP for the demonstration and flag it demo-only.
Do not let this survive into a production configuration.
